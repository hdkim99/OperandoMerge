# Synthetic operando showcase

This third-party-license-free synthetic dataset represents a 600 s catalyst
experiment recorded by five independent instruments. Every source clock
difference is deliberate and appears explicitly in `config.json`.

Every row is generated by `generate_showcase.py`; no proprietary, published, or
third-party experimental data is included. The files are distributed under the
repository's MIT license.

| Source | Raw interval | Clock/alignment | Channel semantics |
|---|---:|---|---|
| Reactor logger | 10 s | absolute UTC reference | temperature, pressure: continuous |
| MFC controller | 20 s | local clock; 100 s event → experiment 120 s | H₂/Ar flow: stepwise |
| MS | 2 s | reported 8 s late; transport delay = 8 s | m/z 44/28: continuous |
| GC | 3 samples | reported 30 s late; sampling 12 s + analysis 18 s | mol%: discrete sample |
| XRD | 60 s | reported 20 s late; offset −5 s and analysis delay 15 s | phase: stepwise; lattice: discrete |

Generate the real CLI report and generic alignment plot:

```bash
mkdir -p showcase-output
operandomerge merge examples/showcase/config.json \
  --excel showcase-output/operandomerge-showcase.xlsx \
  --plot showcase-output/alignment-cli.png
```

Regenerate all source files and the before/after figures from their documented
equations:

```bash
python examples/showcase/generate_showcase.py --output-dir showcase-output
```

Expected invariants:

- canonical timeline: 0–600 s at 2 s intervals (301 rows);
- MS reported 8–608 s → canonical 0–600 s;
- GC reported samples 150/330/510 s → canonical 120/300/480 s;
- GC columns contain exactly 3 measured values and 298 missing values;
- XRD reported 20/80/…/620 s → canonical 0/60/…/600 s;
- all three GC composition rows sum to 100 mol%; and
- the synthetic inputs produce no QC errors or warnings.

The formulas generate plausible visualization data, not a validated kinetic or
diffraction model. They must not be used as physical reference values.
